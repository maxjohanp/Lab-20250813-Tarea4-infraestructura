IDRecomendación CISNivelAntesDespuésEvidencia finalComandos aplicados
1.1.1Enable 'aaa new-model'
Activa AAA: el control de acceso deja de depender de cada línea y se centraliza.		L1CUMPLECUMPLEaaa new-model
1.1.2Enable 'aaa authentication login'
Obliga a autenticarse con usuario y clave (base local) en todos los accesos.		L1CUMPLECUMPLEaaa authentication login default local
1.2.2Set 'transport input ssh' for 'line vty' connections
Telnet envía usuario y clave en texto claro; SSH cifra toda la sesión.		L1CUMPLECUMPLEline vty 0 4: transport input ssh
1.2.3Set 'no exec' for 'line aux 0'
El puerto auxiliar no se usa; con 'no exec' nadie abre una sesión por ahí.		L1CUMPLECUMPLEno exec
1.2.4Create 'access-list' for use with 'line vty'
Define desde qué dirección se puede administrar el equipo y registra el resto.		L1CUMPLECUMPLEACL 113: permit tcp + deny ip any any
1.2.5Set 'access-class' for 'line vty'
Aplica la ACL a las líneas VTY: solo la PC de administración puede abrir SSH.		L1CUMPLECUMPLEline vty 0 4: access-class 113 in
1.2.7Set 'exec-timeout' to less than or equal to 10 minutes 'line console 0'
Una consola olvidada abierta queda disponible para cualquiera; se cierra sola.		L1CUMPLECUMPLEline con 0: exec-timeout 5 0
1.2.9Set 'exec-timeout' to less than or equal to 10 minutes 'line vty'
Cierra las sesiones remotas inactivas para que no puedan ser reutilizadas.		L1CUMPLECUMPLEline vty 0 4: valor por defecto (10 min)
1.3.2Set the 'banner-text' for 'banner login'
El aviso legal antes de iniciar sesión deja claro que el acceso está restringido.		L1CUMPLECUMPLEbanner login configurado
1.3.3Set the 'banner-text' for 'banner motd'
Mensaje del día con el aviso de uso autorizado para todo el que se conecte.		L1CUMPLECUMPLEbanner motd configurado
1.4.1Set 'password' for 'enable secret'
El modo privilegiado queda protegido con una clave guardada como hash.		L1CUMPLECUMPLEenable secret presente
1.4.2Enable 'service password-encryption'
Evita que las claves de tipo 0 se lean a simple vista en la configuración.		L1CUMPLECUMPLEservice password-encryption
1.4.3Set 'username secret' for all local users
Las claves de los usuarios locales se guardan como hash, no reversibles.		L1CUMPLECUMPLEusuarios con secret: admin
2.1.1.1.4Set 'seconds' for 'ip ssh timeout'
Limita a 60 s el tiempo para autenticarse: menos ventana para ataques.		L1CUMPLECUMPLEip ssh time-out 60
2.1.1.2Set version 2 for 'ip ssh version'
SSH versión 1 tiene fallos conocidos; solo se acepta la versión 2.		L1CUMPLECUMPLEip ssh version 2
2.1.2Set 'no cdp run'
CDP anuncia modelo, versión e IP a cualquier vecino: información para un atacante.		L1CUMPLECUMPLEno cdp run
2.1.3Set 'no ip bootp server'
El servidor BOOTP no se usa y es una puerta más expuesta.		L1CUMPLECUMPLEno ip bootp server
2.1.4Set 'no service dhcp'
Este equipo no reparte direcciones; el servicio DHCP sobra y se apaga.		L1CUMPLECUMPLEno service dhcp
2.1.6Set 'service tcp-keepalives-in'
Detecta y cierra sesiones entrantes colgadas que ocupan líneas VTY.		L1CUMPLECUMPLEservice tcp-keepalives-in
2.1.7Set 'service tcp-keepalives-out'
Detecta y cierra sesiones salientes colgadas.		L1CUMPLECUMPLEservice tcp-keepalives-out
2.1.8Set 'no service pad'
PAD (X.25) es un servicio heredado que no se usa.		L1CUMPLECUMPLEno service pad
2.2.2Set 'buffer size' for 'logging buffered'
Guarda los eventos en memoria para poder revisar qué pasó en el equipo.		L1CUMPLECUMPLElogging buffered 64000
2.2.3Set 'logging console critical'
Solo los eventos críticos van a la consola: no la saturan ni frenan el equipo.		L1CUMPLECUMPLElogging console critical
3.1.1Set 'no ip source-route'
Impide que el emisor elija la ruta del paquete para saltarse los controles.		L1CUMPLECUMPLEno ip source-route
